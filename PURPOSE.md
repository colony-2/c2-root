This cell is the root cell for a project. Its primary purpose is to evaluate the creation of new cells and route general feature requests to the appropriate owner. The JobDB registry supplies the current cell inventory.

List registered cells using `c2j cells` or `c2j cells --json`.

To better understand what cells do, you can read their README.md, AGENTS.md and PURPOSE.md files and/or peruse their contents.

Use the shared recipes repository's creation recipe to review a new cell's name, repository and exact purpose, register it, and initialize its repository. Creation does not edit root configuration or create a root commit.
